# Unemployment Analysis with Python

## Project Overview

This project performs Exploratory Data Analysis (EDA) on unemployment data in India to identify regional and temporal unemployment trends, with a focus on understanding the impact of the COVID-19 pandemic on unemployment rates.

The analysis uses data visualization and statistical exploration techniques to study unemployment patterns across Indian states/regions.

---

## Objective

The main objectives of this project are:

- Analyze unemployment trends across different regions of India.
- Study monthly changes in unemployment rates over time.
- Compare unemployment patterns among different states/regions.
- Identify regions with the highest average unemployment rates.
- Analyze relationships between unemployment rate, employment, and labour participation rate.
- Compare unemployment levels before and after the COVID-19 period.

---

## Dataset

**Dataset Name:** Unemployment in India

**Source:** Kaggle

The dataset contains unemployment-related information including:

- Region (State)
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Rural/Urban)

## Project Workflow

The analysis follows these steps:

### 1. Data Loading and Inspection

Performed:

- Dataset loading
- Dataset shape analysis
- Data type inspection
- Missing value checking
- Date format conversion

---

### 2. Exploratory Data Analysis (EDA)

The following analyses were performed:

### Regional Analysis

Calculated average unemployment rates for different Indian regions/states to identify regional variations.

### Time-Series Analysis

Analyzed monthly unemployment trends to understand changes over time.

### Regional Trend Comparison

Compared unemployment trends of multiple regions using time-series visualization.

### Top 10 Regions Analysis

Identified regions with the highest average unemployment rates.

### Correlation Analysis

Examined relationships between:

- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)

using a correlation heatmap.

### COVID-19 Impact Analysis

Compared average unemployment rates between:

- Pre-COVID period
- Post-COVID period
